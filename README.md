# Capstone Project - Komik

Project ini merupakan program CRUD (Create, Read, Update, Delete) sederhana menggunakan Python untuk mendata komik favorit.

## Data Structure

Program menggunakan struktur data dictionary yang berisi beberapa list:

- ID
- Judul
- Genre
- Rating
- Author

## Features

### 1. Show Komik
Menampilkan seluruh data komik yang tersedia.

### 2. Search Komik
Mencari komik berdasarkan judul.

### 3. Add Komik
Menambahkan data komik baru ke dalam list.

### 4. Update Komik
Mengubah data komik berdasarkan ID.

### 5. Delete Komik
Menghapus data komik berdasarkan ID.
